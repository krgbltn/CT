# Шпаргалка по агентам юридических лиц

## Общие слоты

- `classifier` — ИИ-агент для возврата.
- `next_article` — необязательная статья продолжения.

## `find_account_by_inn.js`

Ищет ЛС юридического лица по ИНН.

| Параметр | Значение |
|---|---|
| Запрос | GET `/api/service/sigurd/ur/abonents_by_inn?inn={inn}` |
| Вход | `inn` |
| Выход | `ur_account_number`, `final_answer` |
| `final_answer="1"` | найден первый юрлицо и первый номер ЛС в `WebProperties[]` |
| `final_answer="2"` | массив пуст или у первого юрлица нет номера ЛС |

Пустой ИНН, ошибка API или пустое тело ответа — оператор. Если ЛС несколько, берётся первый.

## `autodial_search.js`

Проверяет, был ли автодозвон по задолженности для юрлица.

| Параметр | Значение |
|---|---|
| Запрос | GET `https://autocalls.enplus.group/api/kc/debt-call?phone={phone_ul}&ul=1` |
| Вход | `phone_ul` |
| Выход | `autodial_ls`, `final_answer` |
| `final_answer="1"` | `debt_call.exists === true`, номер ЛС записывается в `autodial_ls` |
| `final_answer="2"` | автодозвона нет |

Таймаут задан настройкой `timeoutMs` и по умолчанию равен 3 секундам. Пустой телефон, ошибка API или таймаут — оператор.
