# Шпаргалка по агентам отключений ТСН

Для идентификации используется общий `../Идентификация общая/identification.js`.

## Общие слоты

- `uid` — ID выбранного ЛС.
- `classifier` — ИИ-агент для возврата.
- `next_article` — необязательная статья продолжения.

## Агенты

| Агент | Запрос и вход | Выход и логика |
|---|---|---|
| `disabling_tsn.js` | GET `/{uid}/disconnections_heat`; вход: `uid` | Возвращает `debt`, `house_type`, `disconnection` (JSON), `disconnection_text`, `work_type`. `final_answer="1"` — есть `disconnection`; `"2"` — отключения нет, но есть долг; `"3"` — нет отключения и долга. |
| `disabling_tsn_plan.js` | GET `/{uid}/disconnections_heat`; вход: `uid` | Возвращает `disconnection_text`, `date_end`. `final_answer="1"` — дата окончания уже наступила; `"2"` — работы ещё идут; `"3"` — отключения или `date_end` нет. Дата ожидается в формате `ДД.ММ.ГГГГ ЧЧ:ММ`. |
| `disabling_notifications.js` | Параллельно GET `/{uid}/notifications` и `/{uid}/info`; вход: `uid` | Возвращает `fio`, `final_answer`. `"1"` — уведомлений нет; `"2"` — уведомления есть. `fio` собирается как «Фамилия Имя Отчество». |

При отсутствии `uid`, ошибке всех обязательных запросов или исключении агенты переводят к оператору. В `disabling_notifications.js` отсутствие ответа уведомлений при успешном `/info` будет трактовано как отсутствие уведомлений.
