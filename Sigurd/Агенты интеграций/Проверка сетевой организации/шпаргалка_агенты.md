# Шпаргалка по проверке сетевой организации

## `check_network_organization.js`

Получает сетевую организацию для выбранного ЛС.

| Параметр | Значение |
|---|---|
| Запрос | GET `/{uid}/network_organization_data` |
| Вход | `uid`, `classifier`; `next_article` переопределяет статью продолжения |
| Выход | `network_organization_id` ← `Id` ответа |

Соответствие ID: `1` — ИЭСК, `2` — БЭСК, `3` — ОКЭ, `4` — другое. Поля `Name` и `Contacts` ответ содержит, но текущий маппинг не передаёт. При ошибке или пустом ответе — оператор. `final_answer` агент не заполняет.
