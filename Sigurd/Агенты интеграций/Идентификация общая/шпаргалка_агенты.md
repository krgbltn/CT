# Шпаргалка по общей идентификации

## `identification.js`

Находит лицевые счета по телефону и помогает выбрать нужный по адресу.

| Параметр | Значение |
|---|---|
| Основной запрос | GET `/contracts_by_phone?phone={phone}` |
| Дополнительные запросы | GET `/{uid}/info`, GET `/{uid}/disconnection_report_info` |
| Вход | `phone` |
| Технические входы | `classifier`, необязательный `next_article` |
| Успешные выходы | `uid`, `contract_no`, `address`, `status_ls`, `city`, `city_1`, `house_type` |

### Логика

1. Один ЛС: спрашивает подтверждение адреса и записывает `id_step="confirm_single"`, `id_selected_index`, `id_contracts_data`.
2. Несколько ЛС: просит назвать адрес и записывает `id_step="ask_multiple"`, `id_contracts_data`.
3. При подтверждении либо сопоставлении адреса заполняет данные выбранного ЛС и переходит в следующую статью.
4. При пустом ответе API, отказе от адреса, невозможности сопоставить адрес или ошибке передаёт `final_answer="error"` и переводит на оператора.

Для нескольких ЛС адрес сопоставляется по словам из ответа клиента: стоп-слова исключаются, остальные слова должны присутствовать в адресе ЛС.
