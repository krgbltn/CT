# Шпаргалка по агентам отключения электроэнергии

## Общие слоты

- `uid` — ID выбранного ЛС.
- `classifier` — ИИ-агент для возврата.
- `next_article` — необязательная статья продолжения.

## `disabling_electro.js`

Проверяет отключение электроэнергии и задолженность.

| Параметр | Значение |
|---|---|
| Запрос | GET `/{uid}/disconnections_electro` |
| Вход | `uid` |
| Выход | `disconnection_text`, `disconnection_type`, `work_type`, `debt`, `house_type`, `final_answer` |
| `final_answer="1"` | в ответе есть объект `disconnection` |
| `final_answer="2"` | отключения нет, но `debt=true` |
| `final_answer="3"` | нет отключения и долга |

При ошибке или пустом ответе переводит на оператора.

## `ksrt_report.js`

Создаёт аварийную заявку в КСРТ на отключение/качество ЭЭ.

| Параметр | Значение |
|---|---|
| Запрос | POST `/{uid}/disconnection_report_info` |
| Вход для тела | `uid`, `message`, `comment`, `phone`, `isbuilding`, `iscounter` |
| Значение `message` | `NoPower`, `Invalid`, `FrequentShutdowns`, `Other`, `LightFlashes`, `NoPhase`, `LowVoltage`; fallback `NoPower` |
| Дополнительно | `isbuilding` и `iscounter` — из одноимённых слотов, по умолчанию `false`; `isfrequent` вычисляется по причине |
| Успех | `final_answer="1"` |

Запрос и поля тела настраиваются в `ksrt_report_settings.json`; `Host: api.enplus.ru` без порта. Комментарий по умолчанию — `Отсутствует ЭЭ` без дополнительных кавычек. Слоты `isbuilding` и `iscounter` принимают `true` / `false`; в API отправляются логические значения. Пустые или отсутствующие слоты дают `false`; перед новым обращением оба слота сбрасываются сценарием. `isfrequent=true` только для `FrequentShutdowns`. Успешный HTTP 2xx, включая `200 OK` с пустым телом, возвращает `final_answer="1"`. Ошибка запроса или неуспешный статус — перевод через `operatorArticle`. Выполняется один POST без GET и автоматических повторов.
