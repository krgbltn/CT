# Шпаргалка по агентам договорной работы

## Общие слоты

- `classifier` — ИИ-агент для возврата.
- `next_article` — статья продолжения; для этих агентов должна быть задана сценарием, так как значение в настройках пустое.

## `contracts_by_address_lastname.js`

Ищет лицевой счёт по фамилии и адресу.

| Параметр | Значение |
|---|---|
| Запрос | GET `/contracts_by_address_lastname` |
| Вход | `last_name`, `city`, `street`, `house` |
| Выход при находке | `uid`, `contract_no`, `final_answer="1"` |
| `final_answer="2"` | массив ответов пуст, не получен или в первом элементе нет `UserId` |

Используется только первый найденный ЛС. Ошибка HTTP в текущей реализации также даёт `final_answer="2"`, а не перевод к оператору.

## `info_by_user_id.js`

Проверяет статус найденного ЛС и получает тип дома.

| Параметр | Значение |
|---|---|
| Запросы | GET `/{uid}/info`, затем GET `/{uid}/disconnection_report_info` |
| Вход | `uid` |
| Выход | `final_answer`, при наличии `house_type` |
| `final_answer="1"` | статус ЛС `Действует` |
| `final_answer="2"` | статус ЛС `Выключен` |
| `final_answer="3"` | статус ЛС `Закрыт` или `Ликвидирован` |
| `final_answer="4"` | другой или отсутствующий статус |

При отсутствии `uid`, ошибке первого запроса или исключении переводит на оператора. Ошибка второго запроса не блокирует передачу статуса, но `house_type` не заполняется.
