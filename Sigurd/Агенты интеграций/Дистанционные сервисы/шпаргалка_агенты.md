# Шпаргалка по агентам дистанционных сервисов

## Общие слоты

- `uid` — ID выбранного лицевого счёта.
- `classifier` — ИИ-агент для возврата.
- `next_article` — необязательная статья продолжения.

## `check_lk_registration.js`

Проверяет регистрацию собственника в личном кабинете.

| Параметр | Значение |
|---|---|
| Запрос | GET `/api/service/sigurd/fl/{uid}/info` |
| Вход | `uid` |
| Выход | `is_owner_registered`, `final_answer` |
| `final_answer="1"` | `account.is_owner_registered === true` |
| `final_answer="2"` | регистрация не подтверждена: `false` или поле отсутствует |

При ошибке API или пустом ответе переводит на оператора.
