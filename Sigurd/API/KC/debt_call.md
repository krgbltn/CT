# debt-call (сервис автообзвона КЦ)

Проверка по базе автодозвона: был ли за последние N суток успешный дозвон абоненту в рамках долговой кампании автообзвона о задолженности. Закрывает задачу Голосового меню КЦ «По базе автодозвона найти клиента, озвучить номер договора, на который поступал автодозвон»: при поиске по телефону в ответе возвращается `ls` — номер лицевого счёта для озвучивания.

Не относится к сервисам Sigurd: другой хост и авторизация (`X-API-Key` вместо Basic).

## Базовый URL

```
https://autocalls.enplus.group
```

## HTTP-запрос

```
GET /api/kc/debt-call
```

## Параметры запроса

| Параметр | Обязательность | По умолчанию | Описание |
|----------|----------------|--------------|----------|
| `ls` | одно из двух | — | Лицевой счёт |
| `phone` | одно из двух | — | Телефон абонента, если ЛС ещё не известен |
| `days` | нет | `3` | Глубина поиска, суток (диапазон 1…90) |
| `ul` | нет | — | `1` — только юрлица, `0` — только физлица, пусто — и те и другие |

## Заголовки

| Заголовок | Значение |
|-----------|----------|
| `X-API-Key` | Ключ доступа. Выдаётся заказчиком отдельным сообщением, в документации не публикуется |

## Семантика `exists: true`

Был успешный дозвон (абонент снял трубку) в рамках долговой кампании автообзвона за `days` суток. В расчёт не входят:

- неуспешные попытки набора;
- ручной обзвон операторами КЦ (другой контур);
- уведомления об отключениях ЕЭИСЦ (другой процесс).

## Модель ответа

```
{
  ls (string) — лицевой счёт
  days (integer) — применённая глубина поиска, суток
  requested_at (string) — время обработки запроса, пояс Иркутск (UTC+8)
  debt_call:
    exists (boolean) — был ли дозвон за период
    last_call_at (string) — дата и время последнего дозвона (UTC+8)
    days_ago (integer) — сколько суток назад был дозвон (0 = сегодня)
    attempts (integer) — количество попыток
    amount (number) — сумма задолженности
    campaign_type_id (integer) — код типа кампании
    campaign_type (string) — тип кампании, напр. «Задолженность ЭЭ»
    campaign_id (string) — идентификатор кампании
    division (string) — подразделение
    is_legal_entity (boolean) — признак юрлица
}
```

Если дозвона не было — тот же `200` и `"debt_call": { "exists": false }`. «Не найдено» ошибкой не считается, 404 не возвращается.

## Пример curl

```bash
curl -s -H "X-API-Key: <ключ>" \
  "https://autocalls.enplus.group/api/kc/debt-call?ls=7891932&ul=0"
```

## Коды ответа и поведение сценария

| Код | Когда | Что делать сценарию |
|-----|-------|----------------------|
| 200 | Штатно, в том числе «не найдено» | Работать по `debt_call.exists` |
| 400 | Нет ни `ls`, ни `phone`; `days` вне 1…90; некорректный `ul` | Не повторять, идти по ветке «данных нет» |
| 401 | Нет или неверен `X-API-Key` | Не повторять, сообщить владельцам сервиса |
| 403 | Запрос не с разрешённой сети | Не повторять, сообщить владельцам сервиса |
| 503 | Источник данных недоступен | Ветка «данных нет», не блокировать звонок |

Тело ошибки — JSON вида `{"detail":"Нужен ls или phone"}`.

## Примечания для сценария

- Все даты — в поясе Иркутск (UTC+8); `days_ago = 0` означает «сегодня»; глубина `days` тоже считается по иркутскому времени, пересчитывать ничего не нужно.
- Таймаут на запрос — 3 секунды; при любой ошибке или таймауте — ветка «данных нет». Абонент не должен ждать на линии из-за интеграции. Фактическое время ответа ~0.26 с.
- Лицевой счёт числовой и у ФЛ, и у ЮЛ (ФЛ 2–12 знаков, ЮЛ 1–8), по номеру их не различить. Если сценарий работает только с физлицами — передавать `ul=0`, иначе есть риск получить дозвон по совпавшему номеру ЛС юрлица.
- Доступ: метод `/api/kc/*` отвечает только с узлов КЦ (ACD-1 10.128.35.50, ACD-2 10.128.35.51, узлы Wiki/Bot 10.128.35.58–10.128.35.62). Обращаться по имени `autocalls.enplus.group`, не по IP — сертификат выдан на имя.
- Swagger: https://autocalls.enplus.group/docs (раздел kc-service), машиночитаемо — `/openapi.json`; для просмотра ключ не нужен (открывается с терминалов 172.16.51.97, 172.16.49.101).
