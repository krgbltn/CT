# CT — агенты CraftTalk

Репозиторий JavaScript-агентов для платформы CraftTalk, клиентских интеграций,
GPT-сценариев и вспомогательных Python-утилит. Агенты выполняются внутри платформы
с глобальными объектами `message`, `agentApi`, `agentSettings`, `resolve` и другими.
Общего приложения и единой команды запуска из корня здесь нет.

Для задачи сначала выберите папку заказчика, прочитайте её README и 1–3 похожих
агента. Новый агент создавайте на основе существующего. Адреса, ID агентов и коды
статей задавайте через настройки; секреты берите из предусмотренного окружением
источника, не переносите реальные значения в примеры.

Для общего GPT-ядра исходники находятся в
`Craft/jsagent-scripts-main-scripts-gpt/scripts-gpt/gpt-modular/modules/`.
Файлы `gpt_core.js` генерируются и вручную не редактируются.

Новые зависимости не устанавливать. Команды установки из старых README
не отменяют это правило; доступные проверки описаны в [порядке работы](docs/WORKFLOW.md).
