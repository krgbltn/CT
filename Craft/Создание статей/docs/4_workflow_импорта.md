# 4. Workflow импорта статей с примерами вопросов

Общий порядок при новой задаче «добавить статьи из Excel в базу знаний Craft-Talk».

## 0. Подготовка
1. Получить от заказчика:
   - `ProjectId` (например `asopov`);
   - токен (env `CRAFTTALK_TOKEN`);
   - целевой каталог: `SymbolCode` (например `classifier-19d9ad70-...`) — список через `GET /catalog/catalogs` (`reference/catalogs.json`);
   - Excel с данными: какие колонки тема/вопрос/ответ/примеры вопросов, диапазон строк, какие строки пропускать.
2. Уточнить правила:
   - публиковать ли темы (нужно, см. docs/3 п.1);
   - «примеры вопросов» = разметка интентов (добавлять через `markup/add`).

## 1. Сборка данных (скрипты/проверки)
3. Прочитать Excel (`openpyxl`), собрать строки: `row, theme, question, answer, examples[]`.
   - Нормализовать пробелы/переносы (`" ".join(s.split())`) — заголовок = весь текст ячейки целиком.
   - Пропустить строки без ответа (если так решено).
4. Проверить данные перед загрузкой: нет пустых вопросов, количество примеров, дубли тем.

## 2. Импорт (скрипт `import_from_excel.py`)
Порядок операций на каждую тему:
1. **Создать/обновить тему** (`article/update`, корневая, `Answers: []`) → статус 200.
2. **Опубликовать тему** (`article/publish` по ExtId) → статус 200.
3. **Взять категорию темы из дерева** (`GET /catalog/categories`, `ParentCategoryCode="root"`,
   сопоставление по Title + Status=Active) → `Id` и `SymbolCode` категории.
4. Для каждой строки этой темы:
   - **Создать/обновить статью-вопрос** (`article/update`, вложенная, `Answers=[{Id: uuid5, Text, Slots:[]}]`, `Questions: []`);
   - если 400 → найти статью по ExtId (`search`, `EnableRemoved: true`) и повторить с полем `Id`;
   - **Добавить разметку** (`markup/add`): 15 фраз `MarkupText` по `IntentSymbolCode` = SymbolCode статьи;
   - сохранить `MarkupBatchId`.
5. Записать строку отчёта CSV.

## 3. Проверка
6. `check_state.py`:
   - корневых категорий = число тем;
   - сумма вложенных = число статей-вопросов;
   - `article/search` по `ExtSourceId` вернёт только опубликованные (темы) — это норма.
7. Отчёт `import_report.csv`: 0 ошибок, все статьи 200, у всех разметка 200.
   Если отчёт потерян/перезаписан — пересобрать по состоянию системы:
   `python scripts/check_state.py scripts/config_21vek.json --report import_report.csv`
   (порядок тем и `ExtId t{n}` берутся из Excel-конфига, а не из порядка дерева;
   в пересобранном отчёте нет `MarkupBatchId` — API его не отдаёт).

## 4. Завершение
8. Собрать итог для заказчика: сколько тем (Active) и статей (Draft), где отчёт.
9. Повторный прогон: статьи обновятся по ExtId без дублей, НО разметка добавится новым батчем
   (docs/3 п.6) — не перезапускать без нужды.

## Конфиг для нового импорта
Скопировать `scripts/config.example.json` в `config_<источник>.json`, заполнить, запустить:
```powershell
$env:CRAFTTALK_TOKEN='<token>'
python scripts/import_from_excel.py scripts/config_21vek.json
```
Для сухого прогона добавить `--dry-run` (только строки первых строк темы) или `--limit 10`.
