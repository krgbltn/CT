# 1. Структура базы знаний Craft-Talk

## Термины

| Термин | Что это |
|---|---|
| **Проект (ProjectId)** | Идентификатор проекта (из ссылки: `.../app/project/<projectId>/...`). Для Сигурда — `asopov` |
| **Каталог (Catalog)** | Отдельная база знаний («тематика»). Имеет `Id` (GUID) и `SymbolCode` вида `classifier-<GUID>`. Напр. `classifier-19d9ad70-4cbc-4857-87e7-258c0af93eff` («Импорт статей») |
| **Статья (Article)** | Запись с заголовком, ответами, вопросами. Имеет `Id` (GUID, меняется при каждой версии) и `SymbolCode` вида `article-<GUID>` (стабильный в рамках жизненного цикла ExtId) |
| **Категория (Category)** | Узел дерева, отображающий статью. Имеет собственный `Id` (GUID, **отличный** от `Article.Id`) и `SymbolCode` = `article-...` |
| **ExtId / ExtSourceId** | Идентификатор статьи во внешней системе + код источника. Позволяют идемпотентно обновлять статьи |
| **Разметка (IntentMarkup)** | Фразы-примеры для интента статьи = «примеры вопросов». Добавляются через `markup/add` по `IntentSymbolCode` статьи |

## Иерархия (дерево)

```
Каталог (classifier-<GUID>)
└── Корневая статья (тема/каталог-контейнер)   Status: Active (опубликована)
    └── Вложенная статья (вопрос + ответ)      Status: Draft (черновик)
```

### Как задаётся родитель (важно!)

| Уровень | `ParentItemId` | `ParentCategoryCode` | `GrandParentCategoryCode` |
|---|---|---|---|
| Корневая статья | **SymbolCode каталога** (`classifier-...`) | `"root"` | `"root"` |
| Вложенная статья | **Id категории родителя из дерева** (GUID из `GET /catalog/categories`) | SymbolCode родителя (`article-...`) | `"root"` |

⚠️ Для вложенной статьи в `ParentItemId` НЕЛЬЗЯ подставлять `Article.Id` из ответа
`article/update`/`article/publish` — это Id версии, сервер падает с 500.
Нужен `Id` категории из `GET /catalog/categories` (см. `scripts/import_from_excel.py` — там это решается автоматически).

## Статусы статей (`ArticleStatus`)

`Draft` (черновик) → `Active` (опубликована) → `Inactive` (снята с публикации), `Removed` (удалена), `Approval`.

**Ключевое ограничение:** вложенную статью можно создать ТОЛЬКО под `Active` родителем.
Под `Draft` родителем любой `article/update` возвращает 500. Поэтому темы-контейнеры публикуют.

## Права доступа (Permissions)

Формат элемента (все поля обязательны):
```json
{"Type": "All", "Action": "Edit", "Value": "All", "ProjectId": "asopov"}
```
