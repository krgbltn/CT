# 3. Грабли и ограничения API (проверено на бою)

Этот файл — самое важное. Все пункты подтверждены реальными запросами к
`https://cloud.craft-talk.ru` (проект asopov).

## 1. Вложенные статьи нельзя создать под черновиком
`article/update` с `ParentItemId` = черновик (Draft) → **500**.
Работает только под `Active` (опубликованным) родителем.
→ Тема-контейнер публикуется первой, вопросы остаются черновиками.

## 2. Для вложенных статей `ParentItemId` = Id категории из дерева
`Article.Id` из ответа `update`/`publish` — это Id **версии**, оно МЕНЯЕТСЯ при каждом обновлении.
Категория в дереве имеет СВОЙ `Id`. Если подставить Id версии → **500**.
→ После публикации темы получить её категорию через
`GET /catalog/categories` (`ParentCategoryCode="root"`, сопоставить по `Title` + `Status=Active`)
и использовать `Categories[].Id` + `Categories[].SymbolCode`.

## 3. Поле `Questions[]` в `article/update` → 500 (баг продакшена)
Любой непустой `Questions` (с `Type: Example`/`Markup`, с `Id`/без, на Draft и на Active статье) → **500**.
Схема в swagger говорит одно, реальный сервер падает. Частично статья при этом может создаться (пустой заголовок).
→ «Примеры вопросов» добавлять через `POST /markup/add` (это и есть разметка интентов, подтверждено заказчиком).

## 4. Removed-статья не обновляется по ExtId (400)
Если статья в статусе `Removed`, `article/update` по `ExtId` → **400 Bad Request**.
→ Найти статью через `search` с `EnableRemoved: true` и отправить `update` с полем `"Id": <id найденной>`.

## 5. `article/search` видит только опубликованные статьи
Черновики (Draft) в поиск не попадают. Проверять их наличие/состояние через дерево
`GET /catalog/categories`.

## 6. `markup/add` не идемпотентен
Каждый вызов создаёт новый `MarkupBatchId`. Повторный прогон импорта = дубли разметки.
Если нужно переделать — удалять батчи через `markup/delete-batch` (Id батчей в отчёте импорта).
`MarkupBatchId` существует только в отчёте импорта: в отчёте, пересобранном через
`check_state.py --report`, его нет, и API его не отдаёт.

## 7. Один и тот же `ExtId`, но разные данные → несколько категорий
Дубли «Бонусные баллы» в дереве появились от разных ExtId (`t1` и `t99`). В рамках одного ExtId
категория одна (Id стабилен). Не плодить ExtId.

## 8. PowerShell + GET с телом
`Invoke-RestMethod`/`curl.exe` не умеют GET с body как нужно; а `GET /catalog/categories`
требует body. → Использовать Python `urllib` (см. `crafttalk_client.py`).

## 9. Сервер добавляет пустой Answer
Темам, созданным с `Answers: []`, сервер сам добавляет один пустой ответ (`Text: ""`). Это не ошибка.

## 10. Swagger-спецификация — с dev-окружения
`reference/external_v0_swagger.json` скачан с `cloud-dev-5.craft-talk.com`, на проде поведения могут
отличаться (п.3 — наглядный пример). Свежую спецификацию на проде получить нельзя (нет swagger).

## 11. Ошибки возвращаются «пустыми»
500/400 часто без тела — диагностировать через изменение одного поля за раз и логировать статусы.

## 12. Скриншоты в официальном docx не читаются моделью
В `reference/официальная_документация_API.md` — только текст. Примеры вложенных статей в docx
показаны картинками — при неоднозначности проверять на реальных запросах.
